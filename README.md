# Restauracja Esencja - system rezerwacji stolików

Ekskluzywna aplikacja webowa dla prestiżowej restauracji **Esencja** w Warszawie, łącząca wyrafinowaną prezentację kulinarną z zaawansowanym systemem interaktywnej rezerwacji stolików w czasie rzeczywistym.

## Dla kogo jest ta aplikacja?
* **Dla gości restauracji:** Pozwala na zapoznanie się z kartą menu premium, sprawdzenie dostępności i interaktywny wybór konkretnego stolika na planie sali restauracyjnej na wybraną datę i godzinę.
* **Dla właścicieli i obsługi:** Zapewnia przejrzysty panel klienta z historią wizyt, statystykami i automatyczną weryfikacją zajętości miejsc.

## Kluczowe funkcjonalności
* **Interaktywny plan sali (SVG):** Matematycznie precyzyjny plan architektoniczny z odwzorowaniem stolików (2, 4, 6 i 8-osobowych) oraz stref pomocniczych (szatnia, WC, strefa VIP).
* **System rezerwacji real-time:** Blokowanie zajętych stolików na określone przedziały czasowe, walidacja danych kontaktowych (telefon, e-mail) oraz automatyczne dodawanie kaucji do historii konta.
* **Ekskluzywny design:** Projekt dopracowany pod kątem urządzeń mobilnych i desktopów, zachowany w luksusowej palecie barw (Light Velvet Cream / Gold).

## Uruchomienie lokalne

1. Zainstaluj zależności:
   ```bash
   npm install
   ```

2. Uruchom serwer deweloperski:
   ```bash
   npm run dev
   ```

3. Zbuduj wersję produkcyjną:
   ```bash
   npm run build
   ```
